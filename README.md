# Wu, et al Marchantia pSTR

Scripts for statistics and plotting figures in "Polymorphic STRs represent unique genetic signals beyond SNPs associated with climate adaptation in Marchantia polymorpha".

- /data # metadata,
- /figure # raw data, r scripts
- script/ # General scripts used in this study


If you use these scripts, please cite the paper below:

Shuangyang Wu, Shenghan Gao, Sen Wang, Martin Lascoux, Hao Yu. Polymorphic STRs represent unique genetic signals beyond SNPs associated with climate adaptation in Marchantia polymorpha. imetaomics, 2026 inpress.
